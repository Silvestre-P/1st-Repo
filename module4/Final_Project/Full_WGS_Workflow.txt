Full WGS Workflow
Under UseGalaxy.org

Step 1)
Combined the two reads by selecting both and choosing the auto build list option

Step 2) 
Assessed read quality 
Tool: FastQc
Version: Galaxy Version 0.74+galaxy1
Parameters: Input the sequencing reads with default settings
Files downloaded: forward and reverse .html files

Step 3)
trimmed poor quality reads and adapters 
Tool: Fastp
version: Galaxy Version 1.1.0+galaxy0
Parameters: Input the sequencing reads with default settings
File downloaded: fastp report html.

Step 4)
Assessed read quality of the trimmed reads
Tool: FastQc
Version: Galaxy Version 0.74+galaxy1
Parameters: Input the fastp dataset with default settings
Files downloaded: forward and reverse .html files

Step 5) 
Assembled the genome
Tool: SPAdes
Version: Galaxy Version 4.2.0+galaxy0
Parameters: Input the fastp dataset with default settings
file assembled: fastp trimmed output
file downloaded: contigs file

Step 6)
Assessed quality 
tool: Quast
Version: Galaxy Version 5.3.0+galaxy1
Parameters: Input the SPAdes contigs dataset, not the scaffold dataset with default settings but having the PDF output.
File assessed: SPAdes contigs
File downloaded: PDF report

Step 7) 
Filtering contigs shorter than 500bp
Tool: Filter FASTA 
Version: Galaxy Version 2.3
Parameters: Input the SPAdes contigs data and switching the "criteria for filtering on the sequences" to filter the sequence length; minimum length 500bp

Step 8)
Quality assessment using CheckM2
tool:CheckM2
Version: Galaxy Version 1.10+galaxy0
Parameters: Input the filter fasta dataset and on Model Options - Options quality production for both models for each genome

Step 9)
Genome annotation 
tool: Prokka
Version: Galaxy Version 1.14.6+galaxy1
Parameters: Input the filter fasta dataset and select Force GenBank compliance -Yes

Step 10)
Downloaded Prokka.ffn
Opened the file and searched for the full 16S rRNA Fasta sequence. Then copied the whole sequence inputted into the next tool.

Step 11)
Species ID
Tool: Blast
Version: Blastn (Web)
Parameters: Input the 16S rRNA Fasta sequence and selecting the rRNA/ITS database option with high similarity.
-Outcome: Stenotrophomonas (maltophilia) strain with 99.28% identity, 100% Query cover, 0.0 E-value

Step 12)
Build phylogenetic tree
Tool: Type Strain Genome Server
Version: https://tygs.dme
Parameters: Submit the filtered contigs dataset and downloaded

Step 13)
Visualize phylogenetic tree
Tool: Interactive tree of life
Version: v7 (web)
Parameters: Display bootstraps as text

Step 14) 
Average nucleotide identity
Tool: https://www.ezbiocloud.net/tools/ani
Version: Website
Parameters: From NCBI Genome database (https://www.ncbi.nlm.nih.gov/datasets/genome/), downloaded the FASTA file for Stenotrophomonas maltophilia (closest hit on 16S BLAST), Stenotrophomonas Rhizophilia (more distant relative), and Stenotrophomonas Sepilia (closest hit on TYGS). Compared filtered contigs.fasta to the FASTA from maltophilia and Rhizophilia
-Outcome: maltophilia with a 91.45% ani value; Rhizophilia with a 81.75% ani value; Sepilia with a 95.95% ani value

Step 15)
Both options: (1) For virulencefinder or (2) CARD
On UseGalaxy.org
Tool: ABRicate (version: 1.01)
Parameters: Under advanced, select either CARD or VRDB (virulence) default; on Prokka gbk

Step 16)
Search for AMR using ResFinder 
Tool: https://genepi.food.dtu.dk/resfinder
Version: 4.7.2
Parameters: default; filter contigs file

Step 17)
Predict pathogenic potential 
tool: https://genepi.food.dtu.dk/pathogenfinder  Or Pathogenfinder 2
Version: 0.6.0
Parameters: Default; filter contigs file

Step 18)
Secondary metabolites production
tool: https://antismash.secondarymetabolites.org/ 
Version: 8.0.4
Parameters: default; filter contigs file

Step 19)
Search for CRISPR regions
Tool: https://crisprcas.i2bc.paris-saclay.fr/CrisprCasFinder/Index
Version: 1.1.2
Parameters: default; filter contigs file

Step 20)
Look for pathogenticity islands
Tool: https://www.pathogenomics.sfu.ca/islandviewer/upload/
Version: 4
Parameters: click genome upload at the top of the screen; upload prokka GenBank and referencing the Stenotrophomonas maltophilia
